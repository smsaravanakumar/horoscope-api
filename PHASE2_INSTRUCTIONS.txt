PANJAPAKSHI HOROSCOPE API - CLIENT REFERENCE / THIRUKANITHA PHASE 2
===================================================================
Base used: horoscope_api(20261013-171747).zip

ADDITIVE CHANGES ONLY
---------------------
1. New top-level API block: birthCalculationDetails
2. Thirukanitha-style astronomical sunrise/sunset using the existing Astronomy Engine.
3. Udayadhi Nazhigai calculated from the governing sunrise at traditional minute precision.
4. Aadi-Antham Parama Nazhigai calculated from the birth Nakshatra start/end boundaries.
5. Existing API Lahiri ayanamsa formatted as D:M:S. Existing ayanamsa calculation is NOT changed.
6. Client-style planetary table:
   - Lagna + planets
   - absolute longitude D:M:S
   - Nakshatra
   - Pada
   - Nakshatra lord
   - Rasi
   - classical relationship/status: Own/Exalted/Debilitated/Friendly/Neutral/Enemy
   - Rahu/Ketu/Mandi relationship is deliberately returned as --- instead of inventing a disputed convention.
7. Additive Dasha/Bhukti timeline with start/end date metadata.
8. No Bhavam calculation added.
9. Existing horoscopeDetails, Rasi, Navamsa, D1-D60, Gocharam, Ashtakavarga, Mole/Scar and client rules are unchanged.

-------------------------------------------------------------------
Sunrise: 05:57
Sunset: 18:45
Udayadhi Nazhigai: 25.20
Aadi-Antham: about 54.49 with current astronomy engine (client image shows 54.45)
Reference planetary D:M:S values match to within a few arcseconds.

NOTE ON AADI-ANTHAM
------------------
The small difference between 54.49 and the old client printout 54.45 is expected from ephemeris/rounding convention differences. The app uses the current frozen astronomy engine and Lahiri basis rather than hard-coding the sample value.

  node tests/birthCalculationDetailsApiIntegration.test.js
